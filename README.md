# Material Usage Finder

Search a part or material and see which product, model and process it is used in, with its common usages. The dashboard follows the SAP Business One look.

The website itself is static (`index.html` and `data.js`). Python tools turn your Excel parts lists into `data.js` and let you search from the command line.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The website |
| `data.js` | The database the website reads. Generated by Python, do not edit by hand |
| `tools/import_parts_lists.py` | Reads the Excel parts lists and writes `data.js` |
| `tools/parts_lists.json` | Says which Excel file is which product and model |
| `tools/process_overrides.json` | Processes you have checked, so they lose the Suggested tag |
| `tools/search.py` | Searches the database from the command line |
| `tools/requirements.txt` | Python packages (`openpyxl`) |
| `.gitignore` | Keeps the Excel files in `parts_lists/` out of GitHub |
| `.gitattributes` | Tells GitHub that `data.js` is generated, so the language bar counts only the code you wrote |

The process of each material was guessed from its name and shows a **Suggested** tag until you confirm it.

## Add or update a parts list

1. Put the Excel file in a folder named `parts_lists` next to `index.html`.
2. Add a line for it in `tools/parts_lists.json` with its `file`, `product` and `model`.
3. Install the package once: `pip install -r tools/requirements.txt`
4. Rebuild the database: `python tools/import_parts_lists.py`
5. Commit `data.js` and push.

The script reads the newest revision sheet of each file. For MRS it also keeps parts that the newest revision replaced and tags them **Superseded**. It prints every file it imported and every Excel file it skipped.

## Confirm a process

Add the material name and its process to `tools/process_overrides.json`, for example:

```json
{"Solder Bar": "Soldering"}
```

Run the import again. Those records no longer show the Suggested tag. To change the guesses for many materials at once, edit `PROCESS_RULES` at the top of `tools/import_parts_lists.py`.

## Search from the command line

```bash
python tools/search.py solder
python tools/search.py hv998 --product MRS --summary
python tools/search.py oring --model VSM --process Assembly
```

## Deploy with Vercel

1. Push these files to a GitHub repository.
2. In Vercel choose Add New, then Project, and import the repository.
3. Set Framework Preset to **Other**, leave the Build Command and Output Directory empty, and click Deploy.

Every push to the main branch redeploys the site.

## Add or change materials in the website

Use **Add Material…** or the Edit and Delete buttons. These changes are saved in the browser of the person who made them, so other people don't see them. To make a change permanent for everyone, add the parts list as described above.

The website never switches tabs by itself. On the Products & Models tab, **View materials** shows the materials of a model right under its product.

## Note

There is no log in, so anyone who has the site link can read all of the data. Keep the repository private and check company policy before you publish parts lists.
